# gehirn.system

> *"What you can't accomplish alone, you leave for those who come after."*

A bare-metal OS written in Rust, purpose-built for local LLM inference.

## Modules

| module | role |
|--------|------|
| `nerv::` | kernel core |
| `magi::` | memory — Melchior / Balthasar / Caspar |
| `seele::` | scheduler |
| `rei::` | driver layer |
| `unit00::` | GPU / VFIO passthrough |
| `puppet::` | inference engine |
| `ghost::` | internal network stack |
| `wired::` | external internet access |
| `bebop::` | IPC / message bus |
| `section9::` | CLI |
| `lain::` | telemetry / observability |
| `evangelion::` | UI / human interface |

## Status

Pre-alpha. Phase 01 in progress.
